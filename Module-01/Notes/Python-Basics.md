# Python Basics

Python is a high-level, interpreted programming language known for its simple syntax and readability. It is widely used in AI, Machine Learning, Data Science, and automation.

## 1. Variables

Variables are used to store data.

```python
name = "Vansh"
age = 21
cgpa = 7.4
```

## 2. Data Types

Common Python data types include:

- int – Integer values
- float – Decimal values
- str – Text values
- bool – True or False
- list – Ordered collection
- tuple – Immutable collection
- dict – Key-value pairs
- set – Unique elements

## 3. Conditional Statements

Used to make decisions based on conditions.

```python
age = 18

if age >= 18:
    print("Eligible")
else:
    print("Not eligible")
```

## 4. Loops

Loops execute a block of code repeatedly.

**For loop:**
```python
for i in range(5):
    print(i)
```

**While loop:**
```python
i = 0

while i < 5:
    print(i)
    i += 1
```

## 5. Functions

Functions are reusable blocks of code.

```python
def add(a, b):
    return a + b

print(add(10, 20))
```

## 6. Lists

Lists store multiple elements in a single variable.

```python
languages = ["Python", "Java", "C"]

languages.append("SQL")
print(languages)
```

## Conclusion

Python provides simple and powerful programming features that form the foundation for AI and Machine Learning development.
